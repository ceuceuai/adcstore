Hardening applied:
- Every <button> now has explicit type=button or type=submit.
- Form submit buttons explicitly marked submit.
- Browser native alert()/confirm() not used.
- Social-media deletion now requires centered custom confirmation.
- Order status changes now require centered custom confirmation.
- Banner deletion now surfaces database errors.
- Store Settings save now re-reads the saved row from Supabase before showing success.
- Payment save already re-reads database row before success.

Important limitation:
- This is a source/static QA pass, not a live browser end-to-end test against your deployed Supabase/Vercel project.
- Full runtime certainty still requires deployment and clicking each flow against the live database/auth/storage environment.
