- components/AnalyticsTracker.tsx was the ONLY source file using useSearchParams().

- v1.0.31 removes useSearchParams() entirely from AnalyticsTracker. UTM capture remains handled client-side by lib/analytics.ts via window.location.search.

Static validations performed:
- grep source: 0 occurrences of useSearchParams in app/components/lib.
- grep source: trackEvent usages retain imports.
- ZIP integrity test required before release.
