ADCStore v1.0.3 - PANDUAN CEPAT
================================

A. FRESH INSTALL
1. Buat project Supabase.
2. SQL Editor > paste seluruh isi:
   sql/INSTALL_ADCSTORE_v1.0.3.sql
3. Authentication > Users > Add user untuk membuat OWNER.
4. Copy UUID owner dari Supabase Authentication.
5. SQL Editor jalankan:
   insert into public.admin_users(user_id)
   values ('UUID-OWNER')
   on conflict do nothing;
6. Upload source ke GitHub.
7. Import repository ke Vercel.
8. Tambahkan Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
9. Deploy / Redeploy.
10. Owner login: https://DOMAIN-ANDA/owner/login

B. UPGRADE DARI v1.0.2
1. Jalankan sql/UPGRADE_v1.0.2_TO_v1.0.3.sql.
2. Masukkan UUID owner ke admin_users seperti langkah A-5.
3. Push seluruh source v1.0.3.
4. Redeploy Vercel.

C. MEMBER AREA
- Login / daftar member: /member/login
- Dashboard member: /member
- Member tidak bisa mengakses /admin.
- Member dapat memilih 10 preset tema pribadi.

D. THEME OWNER
Admin > Pengaturan:
- 10 preset tema.
- Custom Primary Color.
- Custom Secondary Color.
- Custom Accent Color.
- Tema global otomatis dipakai homepage dan detail produk.

PENTING:
Login OWNER sengaja tidak ditampilkan di homepage. Simpan URL /owner/login secara privat.
