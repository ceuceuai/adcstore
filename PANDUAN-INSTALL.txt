ADCStore v1.0.30 - PANDUAN RINGKAS

FRESH INSTALL
1. Buat project Supabase.
2. SQL Editor > jalankan sql/INSTALL_ADCSTORE_v1.0.30.sql seluruhnya satu kali.
3. Authentication > Users > buat akun pertama. Akun pertama otomatis OWNER.
4. Vercel Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
5. Push source ke GitHub dan deploy ke Vercel.

UPGRADE v1.0.15 -> v1.0.30
1. Jalankan sql/UPGRADE_v1.0.15_TO_v1.0.30.sql sekali di Supabase SQL Editor.
2. Deploy source v1.0.30.
Upgrade ini memperbaiki privilege/RLS penyimpanan Pengaturan; data lama tetap dipertahankan.

CSV KATALOG
Admin > Produk ADC > Import CSV.
Download Template CSV, edit produk/link affiliate di Excel atau Google Sheets, lalu upload. Sistem menampilkan Preview + Validasi sebelum import.
Duplicate slug dapat di-update atau dilewati.


## IMPORTANT - ONE SHOT UPGRADE FROM v1.0.17
If your live ADCStore database is still v1.0.17, run ONLY:
`sql/UPGRADE_v1.0.17_TO_v1.0.30_ONE_SHOT.sql`

That single SQL includes:
- category master
- homepage sorting/filter prerequisites
- media library
- permission audit
- banner permission fix
- final verification

Do not run separate hotfix SQL first.
