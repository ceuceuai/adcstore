ADCStore v1.0.5 - PANDUAN RINGKAS

FRESH INSTALL:
1. Buat project Supabase.
2. SQL Editor > jalankan sql/INSTALL_ADCSTORE_v1.0.5.sql seluruhnya.
3. Authentication > Users > buat akun owner PERTAMA. Tidak perlu query UUID manual.
4. Vercel Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...
5. Deploy source ke GitHub lalu Vercel.
6. Login owner: /owner/login
7. Dashboard > Pembayaran: isi Bank/E-Wallet dan upload QRIS.
8. Produk ADC: tentukan Affiliate / Internal / Both.
9. Akses Produk: isi HTML, tombol login/download, atau keduanya.

UPGRADE DARI v1.0.4:
1. Jalankan sql/UPGRADE_v1.0.4_TO_v1.0.5.sql sekali.
2. Deploy semua file v1.0.5.
3. Environment Variable tidak berubah.

CATATAN AKSES MEMBER:
- Customer checkout internal memakai email.
- Owner ubah status order menjadi Paid/Completed.
- Member membuat/login akun dengan EMAIL YANG SAMA.
- Menu Akses Produk akan otomatis menampilkan akses untuk produk yang sudah Paid/Completed.
