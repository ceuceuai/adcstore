ADCStore v1.0.0 - PANDUAN CEPAT

1) SUPABASE
- Buat project baru.
- SQL Editor > New Query.
- Paste seluruh isi sql/INSTALL_ADCSTORE_v1.0.0.sql > Run.
- Authentication > Users > Add User > buat akun owner.

2) GITHUB
- Buat repository baru.
- Upload seluruh isi paket ADCStore ke ROOT repository.
- Commit.

3) VERCEL
- Add New Project > Import repository GitHub.
- Framework akan terbaca Next.js.
- Environment Variables:
  NEXT_PUBLIC_SUPABASE_URL
  NEXT_PUBLIC_SUPABASE_ANON_KEY
- Deploy.

4) SETUP TOKO
- buka https://domain-anda/admin/login
- Login akun owner.
- Pengaturan: ganti brand, hero, WA, Instagram, footer.
- Produk ADC: edit tiap produk dan masukkan affiliate_url Anda.
- Aktifkan produk yang ingin ditampilkan.
