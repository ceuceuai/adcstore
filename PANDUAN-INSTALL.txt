ADCStore v1.0.9 - PANDUAN RINGKAS

FRESH INSTALL
1. Buat project Supabase.
2. SQL Editor > jalankan sql/INSTALL_ADCSTORE_v1.0.9.sql seluruhnya satu kali.
3. Authentication > Users > buat akun pertama. Akun pertama otomatis OWNER.
4. Vercel Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
5. Push source root-ready ke GitHub lalu deploy ke Vercel.

UPGRADE DARI v1.0.8
1. Jalankan sql/UPGRADE_v1.0.8_TO_v1.0.9.sql satu kali.
2. Deploy semua file source v1.0.9.
3. Tidak perlu fresh install dan tidak perlu hapus data lama.
