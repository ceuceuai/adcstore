ADCStore v1.0.12 - PANDUAN RINGKAS

FRESH INSTALL
1. Buat project Supabase.
2. SQL Editor > jalankan sql/INSTALL_ADCSTORE_v1.0.12.sql seluruhnya satu kali.
3. Authentication > Users > buat akun pertama. Akun pertama otomatis menjadi OWNER.
4. Vercel Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
5. Push source ke GitHub dan deploy ke Vercel.
6. Login owner: /owner/login

UPGRADE DARI v1.0.10
1. Jalankan sql/UPGRADE_v1.0.10_TO_v1.0.12.sql satu kali.
2. Deploy semua file source v1.0.12.
3. Tidak perlu fresh install ulang.
